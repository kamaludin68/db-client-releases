Everything you need for day-to-day database work

Built for developers who want a quick, keyboard-friendly tool that opens in a second and stays out of the way.

SQL editor with autocomplete

Suggests tables, columns, schemas and keywords from your live schema, resolves aliases, and quotes names correctly for each database.

Database navigator

Browse schemas, tables, views, functions, sequences and more in a tree grouped like DBeaver, for every saved connection.

Edit data in the grid

Change cells, add and delete rows, review what changed, then save everything in one transaction or revert.

Table inspector

Data preview with an adjustable row limit, columns, constraints, indexes, triggers and the table's DDL.

Schema editing

Add, change and drop columns, constraints, indexes and triggers from dialogs that show the SQL before it runs.

Export results

Save query results as CSV, TSV, JSON, Markdown or SQL INSERT statements.

MongoDB document view

A Compass-style view with an expandable JSON tree. Edit documents in mongosh syntax and only the changed fields are saved.

Redis browser and console

Browse keys by database, inspect strings, hashes, lists, sets, sorted sets and streams, and run commands in a console.

Private by design

Connects straight from your computer to your database. Passwords are kept in your system's keychain, never in plain files.

Themes

VS Code Dark, GitHub Dark, Dracula and VS Code Light, with matching editor colors.

Supported databases

Every driver is built into the app, so there is nothing extra to download. Paste a connection URL to fill in the connection form.

Install on your desktop

These preview builds are not yet signed, so your system will warn you the first time you open the app.

  1. Download db-client-windows-x64-setup.exe and run it.
  2. If Windows SmartScreen says it protected your PC, click More info, then Run anyway.
  3. Follow the setup. It installs for your account only, with no administrator rights needed, and adds DB Client to the Start menu.

Requires Windows 10 or 11, 64-bit. Uninstall it from Settings → Apps. Prefer no installer? Download the portable db-client-windows-x64.zip, unpack it anywhere and run db_client.exe.

  1. Download db-client-macos.zip. It runs on both Apple silicon and Intel Macs.
  2. Double-click the zip to unpack it, then drag DB Client into your Applications folder.
  3. The app isn't notarized yet, so macOS blocks it the first time. Clear the block with this command in Terminal: 
    xattr -dr com.apple.quarantine "/Applications/DB Client.app"
    Or open the app once, then go to System Settings → Privacy & Security and click Open Anyway.
  4. Open DB Client from Applications or Launchpad.

Requires macOS 12 Monterey or later.

  1. Install the libraries the app uses (most desktops already have them): 
    # Debian / Ubuntu
sudo apt install libgtk-3-0 libsecret-1-0 libegl1 libgles2

# Fedora
sudo dnf install gtk3 libsecret libglvnd-egl libglvnd-gles
  2. Download and unpack the app: 
    curl -LO https://github.com/kamaludin68/db-client-releases/releases/latest/download/db-client-linux-x64.tar.gz
tar -xzf db-client-linux-x64.tar.gz -C ~/.local/share
  3. Run it: 
    ~/.local/share/db-client/db_client

Saved passwords use your desktop's keyring (GNOME Keyring or KWallet), so one needs to be running. Built for 64-bit x86; runs on Ubuntu 22.04 and newer, and distributions of similar age.
